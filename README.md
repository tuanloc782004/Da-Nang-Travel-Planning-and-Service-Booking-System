# 🌏 TripPlanner

AI-powered travel planning system for Da Nang tourism.


## ✨ Features

✅ Smart itinerary generation  
✅ Booking system  
✅ Payment with PayOS  
✅ Wishlist  
✅ Reviews  
✅ Real-time notification


## 🛠 Technology

Frontend:
React + TailwindCSS

Backend:
Node.js + Express

Database:
MongoDB
